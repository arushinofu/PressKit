# Журнал изменений (Changelog)

Все существенные изменения в этом проекте будут задокументированы в этом файле.

Я придерживаюсь принципов [Семантического версионирования](https://semver.org/lang/ru/):
*   **MAJOR (X.0.0):** Глобальные изменения, ломающие обратную совместимость.
*   **MINOR (1.X.0):** Новые функции без ломки старой логики.
*   **PATCH (1.0.X):** Исправления ошибок и мелкие правки.

## [1.0.0] — 2026-02-23

### Добавлено
*   **Система гостей (Guest Flow):**
    *   Отдельная вкладка «Гости» в админ-панели.
    *   Возможность выдачи оборудования без PIN-кода (только ФИО, телефон, Telegram).
    *   Автоматическое удаление гостя из активных после возврата оборудования.
    *   Выбор существующего гостя или создание нового при выдаче.
    *   Отображение пометки «(гость)» и контактов в логах выдачи.
*   **QR-коды (SVG):**
    *   Генерация QR в формате SVG с минималистичным черно-белым дизайном.
    *   Утолщенная рамка для удобной наклейки.
    *   Для одиночного оборудования: номер внутри рамки.
    *   Для паков: имя файла формируется из списка номеров (например, `X111_B656.svg`), без подписи внутри.
    *   Обратная совместимость: старые ссылки `/scan/<id>` работают как редирект на `/scan/<number>`.
*   **Валидация и маски ввода:**
    *   **Дата возврата:** Маска ввода только цифрами с авто-подстановкой формата `ДД.ММ.ГГ ЧЧ:ММ`. Запрет на выбор прошедшего времени (серверная валидация).
    *   **Телефон:** Маска ввода `7 (XXX) XXX-XX-XX` с нормализацией на бэкенде (принимает 8..., +7... и т.д.).
*   **Планировщик задач (Scheduler):**
    *   Фоновая проверка просроченного оборудования через APScheduler.
    *   Логирование события «дедлайн потерян» при наступлении времени возврата.
*   **База данных:**
    *   Добавлено поле `return_date` в модель оборудования.
    *   Runtime-миграция: автоматическое добавление колонки в legacy БД при старте приложения.

### Изменено
*   **Интерфейс (UI):**
    *   Переименованы пользовательские поля на «Название/Описание» в формах и CSV.
    *   Увеличена область нажатия (touch-target) для выбора пользователя (`min-height: 44px`).
    *   Блок «Кто вы?» (Пользователь / Гость) сделан симметричным и лаконичным.
    *   Отображение дедлайнов во вкладках «Оборудование» и «Пользователи» с подсветкой просрочки красным.
    *   Скрытие списка пользователей/гостей в зависимости от того, кто оформляет выдачу.
*   **Логирование:**
    *   Исправлено отображение админских логов: вместо `-` теперь указывается `admin` (в API и CSV).
    *   Формат записи в логах для гостей: `ФИО (гость) [Телефон/Telegram]`.

### Исправлено
*   **Валидация телефона:** Устранена ошибка ложного отказа при правильном вводе номера (теперь нормализуется перед проверкой).
*   **Совместимость QR:** Обеспечена работа старых QR-кодов через fallback-редирект.
